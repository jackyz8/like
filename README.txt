STORM LIKE BOT API

Provider: Games Kinbo Free Fire Info API

1. Open app.py.
2. Replace PASTE_YOUR_GAMES_KINBO_API_KEY_HERE with your own x-api-key.
3. Deploy the ffapi folder to Vercel.

ROUTES
/info?uid=18622776056&region=BD
/Ag-Like?uid=18622776056&region=BD

The /info route returns the player's name, UID, level, region, likes and guild fields from Games Kinbo when available.
The /Ag-Like likes value is DEMO/SIMULATED and does not modify a Free Fire account.
